# Third-party tools

This repository contains Video Saver source code and a generated UI preview. It does not distribute the executables or source trees of its dependencies.

- **Python** — [python.org](https://www.python.org/), [license](https://docs.python.org/3/license.html).
- **yt-dlp** and its optional/default extras — [repository and license](https://github.com/yt-dlp/yt-dlp). The setup helper installs these from the package index into `.venv`; dependencies retain their own licenses.
- **FFmpeg** — [project](https://ffmpeg.org/), [licensing information](https://ffmpeg.org/legal.html). FFmpeg licensing depends on how the binary was built. Install it separately.
- **Node.js** — [project](https://nodejs.org/), [license](https://github.com/nodejs/node/blob/main/LICENSE), optional supported JavaScript runtime.
- **Deno** — [project](https://deno.com/), [license](https://github.com/denoland/deno/blob/main/LICENSE.md), alternative optional runtime.

The README's status badges load from Shields.io when viewed. The running app does not load those badges or any external UI resources.
